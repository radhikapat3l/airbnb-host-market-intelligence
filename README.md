# Airbnb Host Market Intelligence

An Airbnb-style AI market intelligence concept prototype for short-term rental hosts.

This Next.js prototype helps hosts choose a market, analyze neighborhoods, benchmark competitors, simulate pricing, understand guest demand trends, and generate AI-backed listing recommendations.

## Run locally

npm install
npm run dev

Open http://localhost:3000.

## Note

This is a concept prototype created for academic and portfolio purposes. It is not an official Airbnb product.
